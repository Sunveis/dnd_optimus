# 24.1_1 "Оптимус Коч братан"

## 1) Project Goal
Веб-приложение для **D&D-клуба «Оптимус»**. Оно позволяет игрокам, компаниям и корпоративным клиентам узнать об игре, выбрать дату и записаться.
Сотрудники клуба (администратор, мастер и техподдержка) получают заявки в Telegram-боте, обрабатывают их и отвечают на вопросы посетителей.
Аккаунтов и личных кабинетов на сайте нет: вся работа сотрудников проходит в Telegram-боте.

Цель проекта — рассказать посетителям о клубе и помочь им записаться на игру:

- объяснить, как проходит игра (заявка → бронь → подготовка → игра);
- показать, кому подходит клуб (новичкам, опытным игрокам, компаниям друзей, корпоративным командам);
- показать стоимость тарифов со скидками (`price`);
- собрать отзывы игроков (`feedback`);
- дать контакты и карту проезда (`contact`);
- ответить на частые вопросы (FAQ) и дать ссылки на VK и Telegram клуба.

Стек: HTML, CSS, JavaScript (без серверной части и без внешних зависимостей для установки).

Структура репозитория:

```
dnd_optimus/
├── main.html        # главная страница
├── main.css         # общие стили
├── contact/         # страница «Контакты» (карта)
├── feedback/        # страница «Отзывы»
├── price/           # страница «Стоимость»
├── js/              # скрипты (price.js, mapgis.js, mapyandex.js)
├── res/             # изображения и иконки
├── heaven/          # дополнительные страницы
└── changes.md       # журнал изменений команды
```

## 2) Инструкция по запуску

1. Скопировать репозиторий:

   ```bash
   git clone https://github.com/Sunveis/dnd_optimus.git
   cd dnd_optimus
   ```

2. Библиотек нету.

3. Запустить сайт:

   **Просто открыть файл.** Откройте `main.html` в браузере.

4. Для правельного отображения карты на странице «Контакты» нужен доступ в интернет (карты подгружаются из внешних сервисов).
